# Notes App

A full-stack notes app where each user can sign up, log in, and create, edit and delete their own private notes. Built for the 10Pearls Shine internship, Cohort 10 (MERN).

## Tech stack

- Backend: Node.js, Express, TypeScript, MongoDB
- Frontend: React, TypeScript
- Logging: Pino
- Testing: Mocha and Chai (backend), Jest (frontend)
- Code quality: ESLint, Prettier, SonarQube

## Project status

Work in progress. Setup instructions, environment variables and API docs will be added as each part is built.

## Folder structure

- `backend/` for the API
- `frontend/` for the React app
